█ CURRENT BEHAVIOR
─────────────────────────────────────────────────────────────────────────────
When user imports a Shopee product:

  [Import Product]
         ↓
    [Fetch from Shopee API]
         ↓
    [Create Master Product]
         ├─ ✅ Title, Description, Images
         ├─ ✅ All SKUs created
         ├─ ✅ Platform link to Shopee
         └─ ❌ Status = "draft" ← HERE
         ↓
    [Product Created in System]
         ├─ Shows in "Draft Products" section
         └─ Needs activation to appear in main list

█ WHY IS IT DRAFT? (Intentional Design)
─────────────────────────────────────────────────────────────────────────────
1. REVIEW WORKFLOW
   - User inspects imported data
   - Verifies title, description, images are correct
   - Prevents bad data from going public

2. DATA VALIDATION
   - Some SKUs might be skipped (missing seller_sku)
   - Images truncated to 8 (Lazada limit)
   - Descriptions truncated to 5000 chars
   - User should verify no important data lost

3. TESTING GROUND
   - Can test sync to TikTok/Lazada first
   - Verify sync works before activating
   - Only then publish to all platforms

4. INDUSTRY BEST PRACTICE
   - Shopify: Import → Review → Publish
   - TikTok: Draft → Preview → Activate
   - Amazon: Create → Save Draft → Publish

█ RECOMMENDATION
─────────────────────────────────────────────────────────────────────────────
    ⭐ USE OPTION C: ADD "ACTIVATE" BUTTON

WHY:
  1. Users expect imported products to appear in system
  2. They also appreciate a review step before going live
  3. One-click "Activate" button satisfies both needs
  4. Every professional e-commerce platform works this way
  5. Provides audit trail (imported vs. activated timestamps)

RESULT:
  - Draft products show: "🟡 DRAFT — Ready to activate"
  - One click activates: "🟢 ACTIVE"
  - Shows count in sidebar: "3 draft products"
  - Professional, enterprise-grade UX
